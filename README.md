### 🧠 [MindMate](https://github.com/Shriniwas1/Mind-mate)

An AI-powered mental wellness platform combining **NLP and Computer Vision** to provide personalized support.

**Highlights:**

* 🤖 Fine-tuned **DeBERTa-v3-small Transformer**
* 📊 **96.9% accuracy** and **0.95 ROC-AUC** on the trained classification task
* 👁️ Multimodal emotion analysis using **Vision Transformer (ViT)**
* 🔐 Firebase-based authentication and user management
* 💬 AI-powered conversational support
* 🛡️ Designed with privacy and consent considerations

**Tech:** `React` `Node.js` `MongoDB` `PyTorch` `Hugging Face` `DeBERTa` `ViT`

## 💻 Portfolio Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Shriniwas1/portfolio.git
cd portfolio
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start the Development Server

```bash
npm start
```

Open:

```text
http://localhost:3000
```

### 4. Build for Production

```bash
npm run build
```
